📋 Overview
	•	You’ll be implementing a playable version of the game 2048 in Java, but you only need to write the logic — the GUI/interaction code is already provided.  
	•	The graphics and user‐input parts are in the game2048rendering package; your focus is on the game2048logic package (specifically GameLogic.java).  
	•	Games are played on a grid where numbered tiles can slide / merge. The merging rules are described.  

⸻

🎮 Game Rules (Basic)
	•	The board: grid of squares, each either empty or holds a tile with a number.  
	•	Player chooses a direction (up, down, left, right) to tilt the board: all tiles slide in that direction until no more movement is possible.  
	•	If two tiles with the same value collide due to a move, they merge into a tile with double the value. The player’s score increases by the value of the merged tile.  
	•	After each tilt that changes the board, a new tile (value 2 or 4) spawns randomly in an empty square. Your logic doesn’t add new tiles — that’s handled for you.  
	•	The game ends when:
	1.	A tile reaches value 2048 (winning condition)
	2.	There are no valid moves left (no tilt can change the board) → game over.  

⸻

🧩 Tasks (Incremental Steps)

Here are the tasks you’ll tackle, per the specification:
	1.	Task 2: Move Tile Up (No Merging) – implement moveTileUpAsFarAsPossible(int[][] board, int r, int c, int minR) ignoring merges and ignoring minR.  
	•	Example: if there’s a tile at (r, c), and above are empty squares, it should slide up as far as possible.  
	2.	Task 3: Merging Tiles – modify moveTileUpAsFarAsPossible so that it handles merging: if it encounters a tile of the same value it should merge; return value specification included.  
	3.	Task 4: Merging Tiles up to minR – extend your method so that the tile cannot move above a given minR row. This parameter helps with avoiding double merges later.  
	4.	Task 5: Tilt Column – implement tiltColumn(int[][] board, int col) which uses your helper to process a full column (up direction) including merges.  
	5.	Task 6: Tilt Up – implement tiltUp(int[][] board) which tilts the whole board up (call tiltColumn for each column).  
	6.	Task 7: Tilt in Four Directions – support all four directions (up/down/left/right). The spec suggests using board-rotation utilities (rotateLeft, rotateRight) rather than writing separate code per direction.
